# MAIN rulings — M2.2 phase-1 table (A01-A13)

Authoritative. These amend `.agent/archive/contract-m2u2.md` where they differ. Encode every ruling as a test.

| id | ruling |
| -- | ------ |
| A01 | Library surface = `run(inventory_dir, corpus_root, out_dir) -> (list[Event], list[Placement])`, positional, `str \| Path` on every path. **No `strict` parameter** — strict is an exit-status concern of `main(argv)` alone. Also public: `plan`, `validate_generation`, `decode_source_path`, `resolve_source`, `tree_digest`, `render_manifest`, `render_summary`, `SessionsError`, `Event`, `Camera`, `Placement`. `main(argv=None) -> int`. |
| A02 | CONFIRMED as you read it. Always publish. `main` returns 1 iff `--strict` and ≥1 asset held out, else 0; handled domain errors (`SessionsError`, `inventory.InventoryError`, `OSError`) return 2. Artifact content never depends on `--strict`. |
| A03 | CONFIRMED. An empty registry is a valid generation, not an error: emit `events.csv` + `placements.csv` (header rows only), emit `generation.json`, return 0. `multicam.discover_sessions(out)` returns `[]` — its `_looks_like_session` skips every non-directory child, so the three root artifacts are invisible to it. |
| A04 | Vocabulary is `placed` / `held_out`. `placement_reason` is **always nonempty and always pinnable**: literal `"ok"` on a placed row; on a held-out row exactly one of `excluded_asset`, `extension_not_discoverable`, `quarantined_stem`, `source_missing`, `source_path_unsafe`. **It is not the upstream `reason_code`** — this module's vocabulary is coarser on purpose: every quarantine disposition maps to `quarantined_stem` whatever finer reason the registry recorded (`side_missing`, `side_unknown`, …), because a stem that parses to no family has no family to join and the distinction changes no outcome here. The registry keeps the fine reason; join on `asset_id` to recover it. A held-out row carries empty `event_id` and empty `camera_name`. |
| A05 | CONFIRMED exactly. `events.csv:views` = the **raw** view tokens (`above`, not `cam-above`), deduplicated, code-point sorted, `\|`-joined. Manifest `cameras` are emitted in that same view order. Camera **name** and **link name** keep the `cam-` prefix (contract A03); only `views` and the manifest `view` field are raw. |
| A06 | CONFIRMED. An empty upstream `content_sha256` is copied through verbatim and is valid. This module **never reads corpus bytes** — it opens no listed target and hashes nothing outside its own tree, so a `--no-checksums` registry is fully consumable. Registry generation validation, not checksum mode, gates publication. Your synthetic no-checksum case must expect normal placement. |
| A07 | **REJECTED — reject uppercase hex.** Accept exactly `\\` and `\x[0-9a-f]{2}`. `inventory._printable_path` emits `f"\\x{byte:02x}"`, lowercase only, so `\xAB` is a cell that encoder never wrote; decoding it would turn a corrupt cell into a plausible path. Uppercase hex, unknown escapes, truncated escapes, and a lone trailing `\` all raise `SessionsError(reason="source_path_unsafe")`. **Superseded on the outcome by A14: that raise fails the run with status 2; it is not a hold-out.** |
| A08 | **Reject the overflow.** The emitted grammar stays exactly two digits (`^s\d{2}-[a-z]+-[lr]_run-\d{2}$`, `:02d`). A family requiring `run_index > 99` raises `SessionsError` — a 100th run would print an id that fails the pattern this module advertises. Fixed in `plan()`; write the red test with a synthetic 100-asset single-view conflicted family. `spike-m2u2-b` reached the same verdict independently on its own three-digit field. |
| A09 | CONFIRMED, with the ownership proof named exactly. `_assert_owned` adopts a non-empty `--out` iff `generation.json` is present, reads as UTF-8, parses as a JSON **object**, and carries a `generator_version` key. Missing, unreadable, non-JSON, non-object, or foreign (no `generator_version`) → refuse, status 2, contents untouched. Ownership never consults digests: a **stale but well-formed** marker stays adoptable, so P08 regeneration works on a tree whose digests no longer match. `validate_generation`, not `_assert_owned`, is what rejects staleness. This is stricter than the shipped build was; the fix is in. |
| A10 | **Signature is `validate_generation(out_dir, inventory_dir=None)`.** No registry path is recorded in `generation.json` — recording one would bind the tree to a single filesystem layout, the same reason link targets are relative. `inventory_dir=None` validates the tree against itself (both CSV digests + tree digest). Passing `inventory_dir` additionally requires `inventory.validate_generation(inventory_dir)["generation"] == generation["inventory"]`, and that is the only check catching a registry rebuilt under an internally-consistent tree. P09's registry-drift class is therefore a two-argument test. |
| A11 | CONFIRMED. A document cannot digest itself. `generation.json` is compared by **parsed value**, so a whitespace-only or key-order-only reserialization validates. Every semantic edit raises: a changed digest, a changed `inventory` block, a removed key (absent key compares unequal to the recomputed digest), a non-object document, invalid JSON, a missing file. Use a semantic edit for the tamper fixture. |
| A12 | CONFIRMED, with the scope pinned. The tree digest covers **only `--out`'s child directories**: for each, sorted entries, one line per entry, `"<dir>/<entry>\tlink\t<exact target text>"` for a symlink and `"<dir>/<entry>\tfile\t<sha256 of bytes>"` otherwise. **Symlink target contents are never read** — `is_symlink()` is tested before any read, so corpus bytes stay outside the digest and outside this module. Root files are excluded: both CSVs carry their own digests and `generation.json` cannot digest itself. Known and accepted: an injected **empty** directory at root contributes no line and validates — `_looks_like_session` skips it too, so it can produce no session and no divergence between validation and discovery. An injected directory holding any entry is caught. |
| A13 | CONFIRMED. Initial publish = 1 rename (`staging → out`). Replacement = 2 (`out → retiring`, `staging → out`). Staging and retiring are always **siblings** of `--out` named `<out>.staging.<pid>` / `<out>.retiring.<pid>`, and both are removed in a `finally`. A brief interval where `--out` does not exist is allowed; a partially built **child under `--out`** never exists, which is the property to instrument. |

## A14-A15 — later rulings, authoritative over anything above

**A14 hold-out versus failure.** A hold-out is a *qualification* verdict on an asset the registry described correctly. Only three reasons remain: `quarantined_stem`, `excluded_asset`, `extension_not_discoverable`. A **canonical** row this tool cannot decode or resolve means the registry disagrees with the corpus, so `plan` raises and `main` returns **2** and publishes nothing. `source_missing` and `source_path_unsafe` are error reasons, not placements. Contract §3 requires every canonical asset to reach the tree; a hold-out there would drop a camera from an event and publish the smaller event as if whole. This supersedes A04's five-reason list and A07's hold-out outcome.

**A15 tree digest widened.** The digest now covers **every entry under `--out` except `generation.json`**, recording each relative name, each entry's **kind**, each symbolic link's exact target text (via `os.readlink`, because `Path.readlink` drops a leading `./`), and each regular file's bytes. Link target *contents* stay outside. A12's concessions are **superseded**: an injected empty directory, an unexplained root file, and an event directory replaced by a link to an outside directory now all raise.

Also settled since the table above: `generation.json` has a **closed** five-key schema (`events.csv`, `placements.csv`, `tree`, `inventory`, `generator_version`) and `generator_version` is compared, so an added or renamed key raises. `run.main` now accepts `argv`, but keeps its `SystemExit` convention — assert with `pytest.raises(SystemExit)` and check `.value.code`. `generation.json` **is** the block, flat; there is no `generation` key to index.

## Remaining suite scope — P05-P18

Flushed: P01-P04 (7 tests). Every predicate below still needs at least one test. Contract §5 + §9 define them; the rulings above resolve every reading.

- **P05** `multicam.discover_sessions(out)` returns exactly the `events.csv` row set; `Session.session_id == event_id`; every camera resolves to an existing regular file.
- **P06** `pose-estimation-run --list-sessions --sessions-dir <out>` exits 0 and reports the same count.
- **P07** determinism: shuffled `iterdir`, four locales, changed `PYTHONHASHSEED`, changed `TZ`, different `--out` name → byte-identical CSVs, manifests, directory names, entry names, link targets.
- **P08** idempotency + stale removal: rerun over a populated tree restores exact equality with a fresh oracle; an entry injected between runs is gone afterwards.
- **P09** `validate_generation` tamper classes: edited `events.csv`, edited `placements.csv`, semantically edited `generation.json` (A11), removed session directory, removed symlink, drifted registry (A10, two-argument form). Valid set returns the block.
- **P10** the generator calls `inventory.validate_generation` **before** reading a row and propagates `InventoryError`.
- **P11** `decode_source_path` round-trips `\\`, `\x0a`, `\xc2\x80` (U+0080) and `\x80` (non-UTF-8 byte) to four distinct paths; malformed input per A07 holds out rather than crashing. Synthetic only — the live corpus has zero escaped cells.
- **P12** every emitted symlink name ends in a lowercase member of `multicam.VIDEO_EXTENSIONS` and `_find_glob_for_name` resolves it.
- **P13** redaction: no console line, and no manifest value, carries a corpus filename or subject directory name.
- **P14** publication: two-rename swap per A13; no partially built child is ever visible under `--out`.
- **P15** no corpus directory listing occurs — instrument `iterdir`/`glob`/`rglob`/`scandir` and assert zero calls against the corpus root.
- **P16** every symlink target is relative and resolves to a regular file under `--corpus`.
- **P17** a non-empty unowned `--out` is refused, status 2, contents intact (A09 gives the four refusal shapes).
- **P18** both the manifest-without-`file` path and the glob path accept an out-of-tree symlink target — regression pin so the `.agent/polish.md` symlink-consistency item cannot silently break this tree.
