## 2. Design decisions

**D01 — SPARC as published.** Balasubramanian, Melendez-Calderon, Roby-Brami & Burdet (2015),
*JNER* 12:112, DOI 10.1186/s12984-015-0090-9, reference implementation. For a speed profile `v`
of `n` samples at `fs` Hz:

1. `nfft = 2^(ceil(log2(n)) + pad_level)`, `pad_level = 4`; `V = |FFT(v zero-padded to nfft)|`;
   frequencies `f_k = k · fs / nfft`, `k = 0 … nfft − 1`; `V ← V / max(V)`.
2. Keep `f_k <= fc`, `fc = min(SAL_FREQ_CUTOFF, fs / 2)` (10 Hz; the Nyquist clamp is this repo's
   guard, inert at the corpus's 30/60 fps).
3. Adaptive cutoff: within that band, keep the index range from the first to the last `V_k >=
   amp_th`, `amp_th = 0.05`.
4. `SPARC = −Σ sqrt((Δf / (f_last − f_first))² + (ΔV)²)` over the kept range; a kept range of one
   frequency gives 0.

**D02 — guards unchanged.** Non-finite samples are dropped first (as today); `n < 4` or
`fs <= 0` → `NA`; `max |v| < 1e-10` → 0 (no movement). The window pipeline's interior-gap linear
fill and edge-gap `NA` stay exactly as they are.

**D03 — one function, every consumer.** `spectral_arc_length` keeps its name and signature
(`v, fs, fc = SAL_FREQ_CUTOFF`) and gains `amp_th` + `pad_level` arguments with the D01
defaults. Every existing call site (2D windows `wrist_sal`, 3D reach segments `smoothness_sal`)
therefore moves to SPARC together. Column names do not change — the published schema is frozen
(A10) — so the change is carried by `METRIC_METHOD_VERSION` v3, which every clinical artifact
already stamps.

**D04 — the legacy oracle moves with the method.** `tests/test_r_trajectory_kernel.py::
test_gapfree_metrics_are_bit_identical_to_legacy[*-sal]` pinned the fixed-cutoff arc length. Its
`legacy_sal` becomes an independent transcription of the D01 reference; `nj`, `v_mean`, `v_peak`
and `efficiency` oracles are untouched. Evidence for the change = this contract + the user's
ruling.

**D05 — primary + secondary, stated where a reader meets them.** Labels: `wrist_sal` ja
`手関節スペクトルアーク長(SPARC)`, en `Wrist spectral arc length (SPARC)` — ASCII additions only, so the
review UI's Japanese font subset needs no new glyph. `docs/technical/cohort.md` and
`docs/technical/analysis.md` state SPARC as the primary smoothness feature and
`normalized_jerk` (wrist, fingertip) as secondary, with the reason: log dimensionless jerk is
severely distorted by noise even at SNR = 100 where SPARC stays robust near SNR ≈ 10
(Balasubramanian 2015). The consumer schema (`../rehab/schema/columns.yaml`) has no rank field
(roles: feature, outcome, id, meta), so no descriptor key is invented.

## 3. Predicates

Tester-owned (diff-blind; R through the repo's `Rscript` harness as the existing R suites do; a
Python reference as differential oracle):

- **P01** Differential: for generated speed profiles (lengths 4-600, fs in {15, 25, 30, 60},
  smooth bell, multi-peak, noisy, constant, near-zero), R `spectral_arc_length` equals an
  independent Python transcription of D01 within 1e-9.
- **P02** Known values: a single minimum-jerk bell speed profile scores above (smoother than) the
  same bell with two superimposed sub-movements; a constant nonzero profile scores 0.
- **P03** Guards: `n < 4` → NA; `fs <= 0` → NA; all-zero → 0; NA samples dropped before the
  length test; `fc` above Nyquist clamps.
- **P04** Adaptive cutoff is live: for a profile whose normalised spectrum falls below 0.05
  before 10 Hz, the score differs from the fixed-band arc length over `[0, fc]` and equals the
  reference; for one whose spectrum stays >= 0.05 through 10 Hz, the kept range is the whole
  band.
- **P05** Version + labels: `METRIC_METHOD_VERSION == "v3"` and it reaches the emitted
  `metric_method_version` column; cohort `wrist_sal` labels equal D05's; the temporal panel label
  names SPARC.
- **P06** Consumers: the 2D window path and the 3D reach-segment path both call the same
  function (a monkeypatched `spectral_arc_length` in R changes both outputs).

MAIN-owned:

- **P07** R goldens regenerated with the method change alone: every golden column other than
  `*_sal` and the version stamps is byte-identical before and after.
- **P08** The corpus republish carries `metric_method_version = v3` on every clinical artifact.

## 6. Negative controls

1. Drop the zero-padding (`nfft = n`) → P01 fires.
2. Drop the adaptive cutoff (keep the whole ≤ 10 Hz band) → P01 + P04 fire.
3. Normalise frequency by `fc` instead of the kept range → P01 fires.
4. Leave `METRIC_METHOD_VERSION` at v2 → P05 fires.
