# Contract — M4.2 public screening

Tier `kernel`. Base = the commit carrying this file. Frozen at dispatch; amendments append to §8.
Purpose: rank pose-model arms on public 2D ground truth through this deployment and keep a diverse
finalist set for M4.3. Screening selects no production model. M4.1 found agent judgments + agent
coordinates unable to resolve fine hand accuracy in-domain, so fine accuracy is measured here.

## 0. Exposure ledger

Seen before freeze: COCO val2017 body-17 OKS of 4 RTMW arms (600 GT-box crops); RTMW-m
COCO-WholeBody results (this unit's code, run during M4.1: wholebody AP 0.634, hand AP L 0.548 /
R 0.520, hand PCK@0.1 0.551); judge-pair truth (RTMW-X closer on 86/120 COCO-WB hand joints);
general-purpose-7's RTMW-X 500-person subset (wholebody AP 0.685, hand AP 0.604 / 0.608).

## 1. Artifact

- `scripts/bench.py public-eval --arm <name>`: every non-crowd COCO-WholeBody v1.0 val person
  (box w, h > 1 px) through the arm with its GT box, predictions cached
  (`.scratch/bench/public/<arm>/coco_wb_pred.npz`), mmpose-format results scored by
  `tools/cocowb-eval` (xtcocotools 1.14.3, mmpose's six COCOeval passes, `use_area=True`), plus
  hand PCK@{0.05, 0.1, 0.2} of the GT hand-box diagonal (all annotated joints, `c > 0`; and the 5
  feature joints), arm-joint PCK@{0.02, 0.05, 0.1} of the person-box diagonal (shoulders, elbows,
  wrists, `v = 2`), and arm-joint visibility AUROC (raw score, `v = 2` vs `v = 1`).
- `tools/cocowb-eval/` — own uv project, Python 3.12 (xtcocotools' setup breaks on 3.13's PEP 667).
- Manipulation sets (D02) via `scripts/bench.py public-eval --set <name>` adapters, one per set.

## 2. Design decisions

**D01 — arms.** RTMW-m 256 (shipped), RTMW-L 256, RTMW-L 384, RTMW-X 384 (cocktail13 ONNX),
DWPose-L 384, and every Sapiens / Sapiens2 size whose weights load (general-purpose-7 port), all
GPU f32 except where only CPU compiles. Same GT boxes for every arm (pose-only protocol); detector
arms are screened separately in M4.3 end to end.

**D02 — manipulation GT.** DexYCB subject-01 test-split frames (one annotated hand, 21 joints, 8
exo cameras; person box = the detector's box containing the GT hand, else excluded and counted),
HInt NewDays (hand joints + occlusion labels: visibility AUROC per arm on hand joints), ARCTIC /
Ego-Exo4D when the user's registrations land. Each set reports its own numbers; no pooled score.

**D03 — finalist rule.** An arm is a finalist when no other arm beats it on BOTH COCO-WB hand AP
(mean of left + right) and DexYCB hand PCK@0.1 by more than its 95 % bootstrap interval (images
resampled), plus the shipped RTMW-m as the baseline finalist. Arm-joint PCK@0.05 within 0.01 of
the best arm is required (body accuracy cannot be traded away for hands). The set is reported
with every arm's full table; ties keep both.

## 3. Predicates

- **P01** `tools/cocowb-eval` on a synthetic GT/result fixture: a perfect prediction scores AP
  1.0 on every part; a prediction with one hand shifted scores hand AP < 1.0 and body AP 1.0;
  the fixture's AP values are pinned as a golden (`tests/fixtures/cocowb_eval/`), regenerated by
  the tool and compared by the main suite without importing xtcocotools.
- **P02** `public-eval` result rows: every person once, mmpose field split 17/6/68/21/21, score =
  mean raw score; hand PCK + arm PCK + AUROC exact on a synthetic `GtPerson` fixture; AUROC equals
  the Mann-Whitney form incl. ties; an empty class raises.
- **P03** DexYCB adapter maps the 21 DexYCB joints to COCO-WB hand order by a declared table and
  excludes `-1` joints; a synthetic record round-trips.
- **P04** Finalist rule over a constructed table: dominance on both metrics removes an arm; a
  body-PCK shortfall > 0.01 removes it; the baseline always stays.

MAIN-owned: **P05** every arm's tables + the finalist set recorded in `docs/technical/benchmark.md`
with populations (persons, hands, joints) beside every number.

## 6. Negative controls

- NC1 a result file with left/right hands swapped scores lower hand AP than the true file (P01).
- NC2 shifting all predictions by 0.2 hand diagonal drops hand PCK@0.1 to ~0 (P02).

## 8. Amendments

- A01 — P01's golden = the gate step itself: `check.py` runs the real xtcocotools scorer on the
  synthetic fixture and asserts each AP, since the main suite's venv carries no xtcocotools and a
  subprocess from the suite would repeat the gate step. The step also asserts
  `bootstrap.accumulate_ap` = COCOeval on a mixed result over the full set, with one image
  dropped and one image drawn twice (planted mutants: npig ignoring draw counts → 2 FAIL rows;
  no precision envelope → 3 FAIL rows; rc 1 each).
- A02 — D03 "beats it by more than its 95 % bootstrap interval" = the paired percentile interval
  of (other − arm), 1000 image resamples shared by every arm, lies above zero; COCO-WB hand AP =
  mean of left + right AP per resample (`tools/cocowb-eval/bootstrap.py`, COCOeval matches per
  image reused, accumulation weighted by draw count); DexYCB = one hand per image, PCK@0.1 over
  annotated joints of detector-covered hands (`bench.py screen`).
- A03 (user rulings) — Sapiens2-0.4B f16 + flip TTA (general-purpose-7 port; 500-person subset,
  seed 20261019): hand AP mean 0.626 vs RTMW-L 384 0.650, paired −0.024 [−0.063, 0.018], body AP
  0.792, arm PCK@0.05 0.941, ~1.37 s per person (~17× RTMW-L 384). D03 would keep it (not beaten
  on both metrics; DexYCB unrun); the user dropped it — no hand-accuracy gain at ~5 GPU-days per
  corpus run. ARCTIC / Ego-Exo4D / UBody stay unrun (registration absent); the user closed
  screening on COCO-WholeBody + DexYCB + HInt. Finalists: RTMW-L 384 + the RTMW-m baseline.
- A04 (user rulings) — corpus cost ceiling: one full corpus run (337 090 frames) <= 1 day of iGPU.
  D03 ranks only arms whose projected corpus run fits the ceiling; an arm over it is screened,
  recorded and never a finalist. Projection = 337 090 × (measured s/person + 0.1205 s, the
  non-pose share of RTMW-L 384's measured run) / 86 400. Sapiens v1 (HF-gated
  `noahcao/sapiens-pose-coco`, access granted; `f35f83e`), GPU f16, the A03 500-person draw, paired
  hand AP vs RTMW-L 384: 0.3B −0.085 [−0.120, −0.049] (2.0-3.3 d), 0.6B −0.018 [−0.048, 0.015]
  (3.4-6.4 d), 1B +0.026 [−0.006, 0.057] (4.5-8.6 d), 2B +0.042 [0.007, 0.078] (10.4-20.5 d;
  no flip / flip) → every size over the ceiling; dropped, DexYCB unrun. SDPose-Wholebody stops at
  its latency gate: GPU f16 481 ms/call → 2.35 / 4.22 d, accuracy unscreened. Finalists unchanged:
  RTMW-L 384 + the RTMW-m baseline.
