# Contract — M2.7.2 · de-identified regression fixtures for `calibration_qc/`

Frozen acceptance contract. Predicates bind; every downstream artifact decides against them.
Baseline `02c4239`. Tier `data`. Upstream = `.agent/archive/contract-m2u71.md` (M2.7.1, frozen).

## §1 Scope

M2.7.1 shipped the publisher and pinned its predicates with an inline suite whose inputs are built
in Python under `tmp_path` and destroyed at teardown. **Nothing in the tree pins the publisher's
published BYTES.** M2.7.2 ships that oracle: an idempotently generated, committed, de-identified
fixture set = one valid generation + a failure matrix keyed on refusal reason + a privacy scan.

What the fixture set buys that the inline suite cannot:

1. **A byte oracle.** Every M2.7.1 case asserts a property (row count, header order, idempotence,
   refusal class). A change to `_cell()`'s number formatting, to `_canonical`'s sort key, or to
   `inventory.render_json`'s separators passes all 104 cases and silently moves every published
   byte. A committed generation catches it as a diff.
2. **Refusal identity as data, not as code.** Each negative is a stored input tree plus its expected
   reason code, replayable by any consumer — M2.7.3's report cites the matrix rather than restating
   it, and a reason code renamed in `src/` fails the matrix by name.
3. **A privacy predicate over committed bytes.** `_assert_cells_carry_no_identifier` guards the
   publisher's own output at run time; nothing checks what this repo COMMITS.

Out of scope, explicitly:

- **Changing `src/pose_estimation/calibration_qc.py`.** The fixtures observe the shipped publisher.
  A fixture that cannot be produced is a finding for MAIN, never a source edit. Tier `data` means
  defects fix forward.
- **Real corpus bytes.** No fixture input derives from `videos/`, `inventory/`, `sessions/`,
  `qualification/` or `output/`. D01 makes that a scanned predicate, not a promise.
- **`qualification/` bytes.** M2.7.1 D03 still binds.
- Re-litigating `publication.py` extraction (polish pri 3/M) — M2.7.1 §1 refused it and the ruling
  stands.

## §2 Design decisions, ruled before dispatch

| id | decision | why |
| -- | -------- | --- |
| D01 | **Every fixture byte is generated from a fixed synthetic seed declared in the generator.** Subject ordinals, task and side tokens, media content and arm labels come from module constants in `scripts/make_calibration_qc_fixtures.py`, never from a corpus read. | Makes de-identification a property of construction rather than of redaction. A scan then proves conformance to a declared namespace instead of trying to prove the absence of an open set of secrets. |
| D02 | **Probe scripts are synthetic stubs committed inside the fixture tree**, named `probe_bias_transfer.py` / `probe_calibration_bias.py` to match `PROBE_SCRIPTS`, with fixed one-line bodies. The fixture NEVER digests `scripts/probe_*.py`. | `--probes` is a directory argument (M2.7.1 A06), so a stub directory exercises the identical A04 digest binding. Binding the golden to the real probes would move it on every unrelated probe edit — and the polish register already holds a pending `probe_calibration_bias.py` edit. `tests/test_calibration_qc.py:7` already synthesises the probes for this reason. |
| D03 | **The committed valid generation is a byte golden**, regenerated by the generator and compared byte-for-byte by the check. | This is the whole point of §1.1. The publisher is already pinned deterministic (`test_publication_is_byte_identical_across_two_runs`), and `build_census`/`tree_digest` carry no pid, timestamp or absolute path, so byte equality is achievable rather than aspirational. |
| D04 | **The fixture set binds to its own INPUT digests, never to `src/` source digests.** The check refuses a stale golden by re-running the publisher, not by comparing a recorded `source_sha256`. | The regeneration-fixpoint trap (`.agent/memory.md`): `check_qualify_determinism.py` records `source_sha256` over `SOURCE_FILES`, one of which is a test file, so a test added after regeneration re-breaks the evidence it just produced. Re-running the publisher has no fixpoint — the golden is a function of committed inputs alone. |
| D05 | **The failure matrix is keyed on `CalibrationQcError.reason`**, one directory per reason, and the check asserts the **exception class and the reason string**, never message text. | M2.7.1 §9 class 4 already rules refusals are checked by class; the reason code is the machine-readable half M2.7.1 added (N28-N32) and nothing currently pins the mapping from a corrupted input to its code. |
| D06 | **Reasons unreachable from stored files are recorded in the matrix as `not_file_only` with the state they need**, and the check asserts that set is exactly the declared one. | A matrix silently missing five reasons is indistinguishable from a complete one. Declaring the exclusion makes a newly-reachable reason a check failure rather than an omission. |
| D07 | **The fixture tree lives at `tests/fixtures/calibration_qc_set/` and is committed**, gitignore untouched. **No directory anywhere inside it may be named `calibration_qc`, `qualification`, `sessions` or `inventory`** — the upstream tree is `inputs/upstream/`, the golden is `expected/published/`. | Four `.gitignore` rows are slash-free component names (`inventory:60`, `sessions:78`, `qualification:85`, `calibration_qc:94`), so they match at ANY depth. Measured with `git check-ignore -v`: `tests/fixtures/calibration_qc/x` → ignored by `:94`, and `tests/fixtures/calibration_qc_set/inputs/qualification/y` → ignored by `:85`. A fixture under either name is silently uncommittable, and `git add` reports success while committing nothing. The eight paths of §3 are each verified NOT ignored. Marker FILES are safe: `qualification.json` is not a component named `qualification`, and `qualification.*/` carries a trailing slash so it matches directories alone. |

## §3 Published shape

```
tests/fixtures/calibration_qc_set/
  README.md                 # what this is, how to regenerate, what the scan forbids
  manifest.json             # generator version, synthetic namespace, matrix index, input digests
  inputs/
    upstream/               # a published synthetic qualify generation (v4 shape). NOT named
                            # `qualification/` -- D07, that component is gitignored at any depth.
    probes/                 # 2 synthetic stubs
    evidence/               # bias_transfer.jsonl + bias_transfer.sha256
  expected/
    published/              # the byte golden: 3 entries. NOT named `calibration_qc/` -- D07.
  negatives/
    <reason>/               # one directory per file-only reason, holding ONLY the overridden
                            # input entries plus `expect.json` = {"reason": "<reason>"}
```

A negative directory is an **overlay**, never a full copy: the check materialises `inputs/`, then
applies the overlay, then runs the publisher (or `validate_generation`) and asserts the reason.
Overlay entries may be file writes or deletions (`expect.json` names deletions explicitly).

## §4 Predicates

| id | predicate |
| -- | --------- |
| P01 | The generator is idempotent: two consecutive runs from a clean base produce a byte-identical fixture tree. Credited by MAIN's own rerun. |
| P02 | `expected/calibration_qc/` is byte-identical to what `calibration_qc.run()` publishes from `inputs/`, over all three entries. |
| P03 | `calibration_qc.validate_generation(expected/calibration_qc, qualification_dir=inputs/qualification, probes_dir=inputs/probes)` returns all 7 `GENERATION_KEYS` at `generator_version == GENERATOR_VERSION`. |
| P04 | Every negative raises `CalibrationQcError` whose `.reason` equals its directory name — exception class and reason string, never message text. |
| P05 | Every negative is **minimal and specific**: removing the overlay makes that same replay succeed, so the corruption is what fails and not a second latent defect. |
| P06 | The union of `negatives/` and the declared `not_file_only` set is exactly the 30 distinct `reason=` strings in `src/pose_estimation/calibration_qc.py`, derived from the source at check time rather than from a frozen list. |
| P07 | Privacy scan: no byte of the fixture tree matches a corpus-identifier shape outside the declared synthetic namespace — no real subject ordinal, no corpus filename or path, no absolute path, no `videos/`/`inventory/`/`sessions/`/`qualification/` repo-root path text, and no row-level corpus statistic. |
| P08 | The fixture tree carries no real corpus statistic. The ONLY real numbers permitted are those already committed as module constants in `calibration_qc.py` (`RULED_POPULATION` 178/103, the `RULING` cells, `CLAIMS` text), because the publisher requires them and they are already in the tree. Every other number is synthetic. |
| P09 | `manifest.json` states the synthetic namespace, the matrix index and a digest per input entry, and the check refuses a manifest that disagrees with the tree on disk. |
| P10 | The check runs inside the decisive suite as `tests/test_calibration_qc_fixtures.py` and inside the standalone script, with the script as the single implementation both call. |
| P11 | No fixture file is executable, and no fixture file is a symlink. A symlinked fixture entry would put the oracle's trust root outside the committed set. |
| P12 | Regeneration is reviewable: the generator writes only under `tests/fixtures/calibration_qc_set/` and refuses any other destination. |

## §6 Gate identity

Primary tree, MAIN-run, never beside a decode or inference sweep:

```sh
env -u LD_LIBRARY_PATH PYTHONPATH="$PWD/src" uv run --no-sync ruff check \
  && env -u LD_LIBRARY_PATH PYTHONPATH="$PWD/src" uv run --no-sync ruff format --check \
  && env -u LD_LIBRARY_PATH PYTHONPATH="$PWD/src" uv run --no-sync ty check \
  && env -u LD_LIBRARY_PATH PYTHONPATH="$PWD/src" uv run --no-sync pytest
```

Baseline to beat: **1438 passed / 0 skipped / rc=0** at `02c4239`. The suite costs roughly two
passes (`test_c8_08` spawns a nested full-suite subprocess) → run it detached.

**Unit validator**, the command every fixture artifact decides against:

```sh
env -u LD_LIBRARY_PATH PYTHONPATH="$PWD/src" uv run --no-sync \
  python scripts/check_calibration_qc_fixtures.py
```

rc=0 ⇔ every predicate P01-P12 green. rc=1 ⇔ at least one row unmet, each printed by id.

## §7 Probe-corpus seed

The 30 reason codes, MAIN-derived from the source at seed time. The generator owns the split; the
check re-derives the union and refuses a disagreement (P06).

`arm_duplicate arm_missing cell_alphabet census_digest claim_missing claim_prohibited
corpus_cardinality digest_malformed digest_missing evidence_empty evidence_malformed
evidence_missing evidence_schema forbidden_key forbidden_value generation_foreign marker_shape
marker_unreadable not_owned output_not_directory output_overlap population_mismatch probe_digest
probe_missing probe_stale qualification_stale table_digest table_missing tree_digest
tree_unreadable`

MAIN's expected split, to be corrected by measurement rather than trusted:

- **Run-path negatives** (corrupt an input, call `run()`): `probe_missing evidence_missing
  evidence_empty evidence_malformed evidence_schema forbidden_key forbidden_value arm_missing
  arm_duplicate cell_alphabet population_mismatch probe_digest digest_missing digest_malformed
  not_owned output_not_directory output_overlap generation_foreign`.
- **Validate-path negatives** (corrupt a published tree, call `validate_generation()`):
  `marker_unreadable marker_shape table_missing table_digest census_digest tree_digest
  qualification_stale probe_stale generation_foreign`.
- **Candidate `not_file_only`**: `claim_missing claim_prohibited corpus_cardinality` (each needs a
  monkeypatched module constant, since the ruling and the claim set are constants A02/A05 put
  beyond any argument) and `tree_unreadable` (needs a filesystem permission state git does not
  carry). Each must be recorded with the state it needs.

## §8 Assurance

Tier `data` (roadmap): one structural validator + a live spot-check at close, defects fix forward.
The validator is §6's check script, MAIN-authored, committed and graded both ways at seed — an
all-`unknown` seed exits non-zero, a filled tree exits zero. MAIN's spot-check at close reads the
valid generation's three entries, one negative overlay per path, and the privacy scan's report.
