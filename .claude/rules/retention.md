# Artifact retention — standing user rule

M2's numerical output is eventually destined for the `../rehab` dashboard over the hospital SCI database.

- **Any artifact serving that path is kept whatever the status of the work that produced it, DESCOPED included**, and is never traded away for tree tidiness. Anything off that path is **deleted outright** rather than tagged or archived — a superseded artifact costs a future agent a wrong start. The decisive question is which of the two an artifact is, never how old it is.
- **Operational test for a retained branch or oracle = one named open dependency.** `archive/m2u3-spike-audio` holds because R6's connectivity-reconciliation polish row consumes its `_family_coverage` as the P38 oracle; `archive/m3u3-test` holds because its remaining diff-blind cases are exactly the five cut 3D clinical groups on the `../rehab` path. Everything else went, decided on content rather than label.
- **Prove no-dependency by sweeping `.agent/ scripts/ tests/ src/ docs/` with a positive control before deleting** — an empty search and a broken search print the same bytes.
- **A retained commit survives on an `archive/*` tag, never on its `wt/` branch.** The Close order sweeps `wt/` branches wholesale, taking any retained exception with the rest and leaving its commits dangling — reachable by `git fsck`, pruned by `git gc` once unreachable objects age past `gc.pruneExpire` (2 weeks default). Two named branches were found deleted that way once and are now pinned by tag.
- Pinned: `archive/m2u3-spike-audio` = `049684a` (`scripts/spike_audio_offsets.py` `_family_coverage`, the P38 oracle) · `archive/m2u3-spike-visual` = `f82a9a9` (`scripts/visual_sync_spike.py` `family_recovery_summary`, the only copy of the rule yielding 26/137) · `archive/m3u3-test` = `7026e2c` · `archive/m2u82-test` = `c92ffcc` (M2.8.2's diff-blind suite, an adversarial-review dispatch input) · `archive/m2-review-<name>` (M2 wave-1 reviewer tips; three carry committed red batteries) · `archive/m2u91-test-1` = `a921907`, `archive/m2u91-review-1` = `0fca7cd`, `archive/m2u92-test-2` = `b141a51` (the red-witness test bytes the M2.9.1 / M2.9.2 commit bodies cite; the suites live on, edited, in `tests/`).
- **The prune horizon is 13 days wide in practice, and nothing warns.** `archive/m2u3-spike-visual` was found dangling at day 13 against the 2-week `gc.pruneExpire`, one auto-gc from taking the named input to an open row with it. A row that names a `.scratch/worktrees/<name>` path is citing bytes no ref holds — **resolve that path to a commit and tag it the moment the row is written**, not when the row is worked.
- **Verify with `git tag --list 'archive/*'` before trusting any retention claim**, tag a live wave's tip as its unit closes, and recover an untagged one by matching `git fsck --no-progress | grep 'dangling commit'` against subjects — the tip is the dangling commit in that line with no dangling descendant.
- A red diff-blind or reviewer suite is retained this way rather than in `tests/`, because one red file there takes the decisive gate down (→ `gates.md`).
- **`.agent/archive/` records are frozen and keep their stale pointers.** 15 lines across 7 archived contracts and reviewer reports still cite `.agent/memory.md`, whose law now lives in `.claude/rules/`; earlier records likewise name a `Read()` deny list that no longer exists; and `roadmap.md`, `polish.md` + `review-m2.md` all still address themselves as live attached state under the retired `/session-*` commands. Rewriting a frozen record falsifies it as evidence of what was ruled — the live surface carries the correction instead. Read an archive pointer as a citation of its own time, never as a live path. Live state = `.agent/spec.md` + `.agent/deferred.md` + `.claude/rules/`. `.agent/archive/polish.md`'s rows are frozen with the rest: a `.claude/rules/` bullet calling one "open" cites its own time, and reviving a row means writing it into `.agent/deferred.md` with an acceptance check.
