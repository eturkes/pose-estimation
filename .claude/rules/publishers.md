# The publisher family — one contract, six copies

Publishers: `inventory`, `sessions`, `qualify`, `measure`, `calibration_qc`, `cohort`. Each carries its own copy of the staging/swap/digest/ownership machinery. **Idiom drift is the mechanism behind every defect below — a property lands where it was first ruled and does not travel to siblings, so check each publisher rather than the family.** The extraction into `src/pose_estimation/publication.py` stays DECLINED (M2 review T5 R35); the measured five-way drift is recorded on that `.agent/archive/polish.md` row as its evidence.

## Trust roots — the surface no digest covers

Every self-describing publisher has exactly one unverified file: **its own marker**. `tree_digest` must exclude the marker because the marker carries that digest, so nothing inside the set covers it. Three properties therefore have to be checked directly:

1. The marker is a regular non-symlink file (`lstat` + `S_ISREG`). A symlink puts the trust root outside the set, and where ownership gates a recursive delete it lets a foreign directory license its own deletion.
2. The parse rejects duplicate keys (`object_pairs_hook`); `json.loads` keeps the last silently, so one document carries two claims.
3. The census digest covers the provenance block **minus its own self-referential key** — excluding the whole block leaves the upstream claims consumers trust most as the only uncovered content in the set.

**Properties (1) and (2) are shipped as one shared loader — `inventory.read_marker`** (M2 review T5 R15/R16): `lstat` + `stat.S_ISREG` → `OSError`, then `json.loads` under `inventory.reject_duplicate_keys` as `object_pairs_hook` → `ValueError`; each caller renders both as one refusal in its own error domain. It lives in `inventory.py` because that is the import-graph root — `inventory` imports only `video_io`, and every other publisher already imports `inventory` — so the fix added **zero import edges** and is not the DECLINED `publication.py` extraction. Both `sessions.py` readers route through it, `validate_generation` and `_assert_owned`, the latter being the one with teeth: publication deletes what the marker says this tool owns. Two deliberate non-migrations, each with a reason that outlives its row: `qualify._reject_duplicate_keys` survives as a one-line delegation because `scripts/run_calibration_qc_mutations.py:99,320-321` string-match `object_pairs_hook=qualify._reject_duplicate_keys` under `assert s.count(old)==1`, and `measure._object_pairs` stays because it raises `MeasureError(reason="manifest_duplicate_key")` while `_read_manifest` does not catch `ValueError`. Battery = `tests/test_publisher_trust_roots.py` (16 R15/R16 cases), every refusal paired with the untouched tree validating. **A red witness against a loader without the kind guard needs a timeout: `read_text()` on a FIFO marker blocks.**

**Property (3) ships per publisher, each in its own idiom** (M2 review T5 R17): `cohort.tree_digest(out_dir, marker)` digests the marker minus `generation.tree_digest`; `sessions.marker_digest` is the `marker` key of `generation.json` (the document minus that key, `GENERATION_KEYS` closed over it) — a NEW key rather than a changed `tree_digest` signature, because `scripts/corpus_run_2d.py` + `scripts/pilot_corpus_run.py` call `tree_digest(out_dir)` and the driver computes it before `validate_generation`; `measure.manifest_digest` keeps `generation` minus `generation.manifest`. Battery = `tests/test_publisher_trust_roots.py` `test_r17_*` (an edited upstream block refuses; a recomputed self-digest re-validates — the keyless bound). Adding a self-digest moves every consumer that records the marker: `qualification.json` copies the sessions block + the manifest digest, `calibration_qc.json` copies qualification's, `cohort.json` records `sessions_generation` → republish sessions → measurements (manifest-only `write_axis` per axis, no decode) → qualification → calibration_qc → cohort, then regenerate the fixture set (`calibration-qc.md`) + every campaign naming a touched file.

## Set membership, ownership, staging

- **A set digest over file contents does not cover set membership.** `cohort.tree_digest` folds the sorted entry-name set into the digest, marker excluded so staging and published digests agree. An extra file fails `validate_generation`; content coverage and membership coverage are separate predicates every publisher must satisfy.
- **A prefix-matching name is not an ownership test.** Pids can be reused and any process can create a matching path, so a prefix sweep can delete a foreign directory or the only complete staged generation. `cohort` uses `tempfile.mkdtemp(prefix=…, dir=out.parent)` and cleans this invocation's own paths alone; it has no `_sweep_orphans`. **`sessions.py`, `calibration_qc.py` and `qualify.py` still carry the prefix-name sweep.**
- **Sweep crash debris only after the swap lands.** A kill between the two renames leaves the sole complete generation as a *retired sibling under a dead pid*, so a sweep before the swap deletes it and a failed swap then has nothing to restore. The empty-root rollback needs its own `retiring.exists()` guard too, or it raises `FileNotFoundError` over the real error. `os.kill(int(pid), 0)` raises `OverflowError`, not `ValueError`, on a suffix wider than a C long.
- **Ownership includes the generator version, so a version bump orphans the previous tree.** `_is_own_generation` requires *this* generator's version — which is what keeps a foreign tool's directory from licensing its own recursive deletion — so a bumped generator does not own its predecessor's output and `run` refuses to replace it. Move the previous `--out` tree aside before the first run of a new `GENERATOR_VERSION`; retention follows `retention.md` + the spec's superseded-generation ruling. Pass a kept cohort as `--baseline` when publishing its successor. Not a defect: the alternative is a version-blind ownership test, the hole the check exists to close.
- **Publication replaces a whole tree, so the output is a destructive path.** `--out` must overlap neither `--corpus` nor `--inventory` in either direction; a symlinked `--out` publishes to the path it resolves to, which keeps the link and replaces the tree it named. Publication is per-file atomic, not set-atomic — detection is the guarantee, not prevention.
- **A published tree is unpatchable by any writer.** `tree_digest` covers every entry but `generation.json`, so a stray results file is as fatal as an edited manifest. `_resolve_session_output` must refuse destinations overlapping a published tree in either direction, including defaults; published = a `generation.json` at or above the session directory. Forwarding `--output-dir` alone cannot protect a hazardous default. `session.json` is likewise unpatchable: republish the tree or publish beside it.

## Reading upstream, and validating cells

- **Upstream digests prove bytes, never shape.** `inventory.validate_generation` proves the registry on disk is the one that was published; it says nothing about duplicate ids, an unknown disposition, an absent column, or a `view_conflict` cell contradicting its own rows. Every consumer re-derives what it reads: `sessions.plan` derives the conflict from the canonical rows by the registry's own rule and requires the published cell to agree. A future consumer inherits that obligation.
- **Four validation predicates read as stricter than they are.** `Pattern.match` with `^…$` accepts one trailing newline → every alphabet uses `fullmatch` (an exported pattern needs `\Z`, because consumers call `.match` themselves). `str.isdigit()` is true for superscripts, which then raise `ValueError` out of `int()`, and for other scripts' digits, which `int()` silently normalizes into a value the cell never spelled → require ASCII `[0-9]+`. A CSV with zero rows carries its schema in the header alone, so per-row column checks never run and a short header publishes an empty artifact instead of failing.
- **A cell alphabet must be the token set, never a shape that resembles it.** `[a-z_]+` admits every lowercase token, including statuses outside the contract. `_token_alphabet(frozenset)` derives the pattern from the constant set, so a new partition token reaches its alphabet automatically.
- **Three standard-library calls normalize away the property under test.** `Path.readlink()` drops a leading `./`, so link text compared through it is not the link's text — `os.readlink` is. `Path.is_dir()` follows a symlink, so a directory test alone lets a link to an outside tree pass as a child; take the kind from `is_symlink()` first. `shutil.rmtree(p, ignore_errors=True)` refuses a symlink and swallows the refusal, so link debris survives a cleanup that reports success.
- **A path-prefix containment test breaks at `/`.** `parent + os.sep` yields `//`, which no real path carries, so a filesystem-root corpus classifies every file below it as an escape. Strip the separator from the parent before appending one.
- **Judgment-bearing decisions live in `src/`; drivers orchestrate.** Tests and callers must exercise the same shipped symbol (`sessions.generation_digest`, `corpus_run.asset_disposition`), not a driver-local copy. Script tests can use `runpy`/import loaders; that does not make a driver the owner of shared decisions.
- **`--corpus` is `videos/3-cam`, never `videos`.** `assets.csv` `source_path` is relative to `3-cam`, so pointing one level up fails every row with `SessionsError … reason="source_missing"` before a single measurement runs.
