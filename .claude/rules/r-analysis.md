# R analysis layer — non-obvious hazards

- **`analysis/utils.R:59-87` `aggregate_per_video()` treats every numeric non-metadata column as a feature.** Adding a count, coverage or QC column to an output that legacy consumers read makes it enter per-video means, z-scores, correlations and PCA silently. The R gate grades downstream consumers on discovery + output naming alone (`tests/test_r_consumers.py`; `tests/test_r_pipeline.py` covers the producer, `features.R`, `arthrose_diag.R`), so the full suite stays green while downstream tables change meaning.
- **The 2D/3D partition lives in one reader**: `utils.R` `discover_clinical` (+ `take_mode_arg`, `read_clinical`, `clinical_stem`, `clinical_videos`) selects `CLINICAL_SUFFIXES` per mode positively and stops on a two-mode directory without `--mode`; the six downstream consumers + `make_templates.R` + `validate_metadata.R` route through it, 3D outputs tagged `_3d`, 2D outputs byte-identical to the pre-reader scripts. A new consumer calls it rather than globbing; `tests/test_r_consumers.py` drives every consumer over 2D-only / 3D-only / mixed trees (~33 Rscript runs, 4-7 min under co-tenant load).
- **Consumer discovery selects artifact suffixes positively.** `_aggregate_clinical()` (`src/pose_estimation/validation.py`) selects `_clinical.csv`/`_clinical_3d.csv`; a `windows` substring blacklist misses singular `_clinical_3d_window_qc.csv`. Check every consumer filter when adding an artifact. `analysis/*.R` window globs anchor on `_clinical_windows\.csv$`; directory-mode rescan exclusion is pinned by `test_world3d_outputs_not_rescanned`.
- **Clinical keys depend on the table level.** Shared = `video`/`person_idx`; windows add their window fields, bouts add `side`/`bout_idx` + frame/time bounds (`clinical_features.R` `BOUT_KEYS`). Task, event and subject membership come from validated `sessions/placements.csv`, never from invented CSV identity fields.
- **`analysis/clinical_features.R` is the golden-pinned 2D producer.** Goldens cover four stems (`2d_csv4dp`, `2d_cumsum`, `2d_idx`, `2d_drop`) × frame, window, group-QC, bout and bout-QC artifacts. `nominal_fs()` supplies cadence to rate-based features; bout changes also follow `bouts.md` qualification law.

## Cadence and grids

- Use `stats::filter(x, rep(1/5, 5), sides = 2)` rather than adding `zoo` for `rollmean(x, 5, fill = NA, align = "center")`: NA propagation identical at centre, both edges and every hole pattern; values differ ≤2 ULP (2.8e-14 absolute on ~100-magnitude input) and no golden pins that column. **`dplyr` masks `stats::filter`, so the call must stay namespace-qualified.**
- **Two grids, deliberately.** Evidence counts the window's nominal slots; estimates keep `trajectory_grid()`'s narrower grid anchored on the first observed sample. `compute_window_features()` pads the kernel's `valid` mask by `lead_absent`/`trail_absent` and recounts through `grid_evidence()`. Widening the estimate grid instead would move `nj` through its `T_dur` term and break P08's byte-identical goldens. **A new evidence field must pad; a new estimate must not.**
- **Window enumeration reads `nominal_fs(ts, magnitude = TRUE)`; movement segmentation reads `magnitude = FALSE`** (M2.4). The magnitude is load-bearing: a signed estimate drops a descending clip before any window is keyed, so the QC pass never gets to report `invalid_timebase` (V21-V24). `segment_movements()` keeps the signed form — no QC artifact depends on it, and only C2.07's regex pins that call site, so no numeric oracle proves the site consumes the value.
- **`grid_evidence()` is the single masking path for QC counts** (M3.3). Every frame/interval count, coverage, duration and gap figure must flow through it, so a group's evidence and the metric it explains can never disagree about which samples were usable. Adding a count elsewhere reintroduces exactly the producer/reader disagreement the unit exists to prevent.
- The three-frame gap at 30 Hz lands exactly on the provisional 0.10 s threshold, because `nominal_fs()` reads 30.0000 where the legacy estimator read 30.03 Hz and computed 0.0999 s. **Split slacks are what make that comparison decidable**: `qc_policy_tolerance = 1e-4` relative on gap, `qc_coverage_tolerance = 1e-9` on coverage. One shared 1e-9 slack made the verdict cycle pass/pass/fail with clip length through the residues of 3, so gap and coverage must keep independent tolerances.

## Group and window dispositions

- **Every `(video, person_idx)` group reaches exactly one outcome:** window rows, or one row in `<stem>_clinical[_3d]_group_qc.csv`. Five entry guards cover `n < 4`, non-finite/≤0 `fs`, non-finite bounds, span `< window_sec` and empty `win_starts`. Publish group QC in both modes and always write it, empty or not: absent QC must not mean both “no drops” and “stage never ran.” `GROUP_QC_REASONS` freezes six codes; `group_qc_row` refuses an unlisted one.
- **The sixth disposition covers a loop that emits no windows.** A group passing all five entry guards whose every candidate window fails the `sum(win_mask) < 4` floor emits nothing. The floor stays a window-level rule; `no_windows_emitted` is recorded after the loop. **When an invariant reads "every input reaches exactly one outcome", enumerate the paths that produce NOTHING, not just the ones spelling `next`** — the silent case is the loop that ran and yielded no row.
- **A window-keyed QC table cannot carry a group-level fact, and the 3D-only guard refuses it twice.** A group dropped before any window exists has no window key, and the `is_3d` guard exists because a numeric column on a 2D output enters `aggregate_per_video()` as a feature unnoticed. A separate file escapes both, since consumer discovery selects positively.
- **The group-disposition artifact carries one schema in both modes and takes no 3D identity tags**, unlike `world3d_clinical_3d_window_qc.csv` — D04's reason for a separate file is that one artifact explains dropped groups in either mode, and tagging only the 3D copy rebuilds the per-mode split D04 refused. `test_clinical_golden_schema_exact` exempts `kind == "group_qc"` from both the tag assertion and the non-empty row floor.
- **Freeze each QC header beside its value set.** Group-QC header = `video, person_idx, n_frames, drop_reason, qc_status`; `GROUP_QC_REASONS` supplies its six reason codes. `drop_reason` differs from per-metric window `qc_reason`, and `qc_status` identifies the disposition as a verdict. A cell predicate needs both schema and values.
- `sum(win_mask) < 4` skips a window entirely, so no row exists for it. Any per-window artifact covers emitted windows only, and changing the skip moves the shipped window row set.
- **The 3D path deliberately skips `adapt_2d_confidence()`** (`clinical_features.R:1452-1466`). This looks like a missing gate and is not: `world3d.csv` confidence is a fused mean over already-accepted points, and fusion applied `min_confidence` upstream (`triangulation.py:538,559-572`). Adding a 3D confidence predicate creates a new gate and moves every shipped 3D estimate.
- **The R language server never answers `documentSymbol` for R Markdown**, while `.R` files index at ~4 files/s. An `.Rmd` in an LSP request path burns the full tool timeout instead of returning. Reach `analysis/analysis_summary.Rmd` with `Read`/`rg`; keep it out of every symbol query.
