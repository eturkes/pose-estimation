# Two capture documents, and which governs which

- **`docs/prospective_capture.md` governs a FUTURE calibrated acquisition; `docs/capture_protocol.md` governs a capture made with the tooling this repo ships.** Neither amends the other, and both carry the banner `Which document governs which capture.` naming the other. **The split is forced**: the specification requires 8 cameras, 120 fps, global shutter, a wired trigger, traceable scale and sealed held-out targets, none of which `pose-estimation-calibrate` supports. Merging them would make a shipped operational document state requirements its own commands cannot meet.
- **`P python scripts/check_prospective_capture.py` = 12 predicates in under a second**, driven identically from `tests/test_prospective_capture.py` through `runpy`. It owns the section spine (20 frozen ids + titles), the five per-section fields, the `MUST` binding of the five non-negotiables, the local-decision labelling of the five measured absences, and citation resolvability. Sentence length is no predicate: `CLAUDE.md` `Authoring` keeps text caps out of checks, so a long sentence is a `.scratch/steq.py` lead for judgment (→ `text-register.md`).
- **Imperative prose alone does not satisfy the checker.** Normatively bound sections must state literal `MUST`; P03 checks each governed section, not the number of imperatives.
- **NIST traceability = an unbroken chain to a STATED reference with documented uncertainty at every link** — TN 2156 §5.3.3 allows SI or another specified reference. Requiring the SI metre is this project's choice, not NIST's rule, and §5.2.4 says a certificate number alone does not prove traceability. Anipose's synchronization routes are in its FAQ rather than the paper; BioCV publishes zone statistics rather than a spatial error map.
- **Citation verification stands at 16/20 rows.** L1's absence is `confirmed`; **L2-L5 are unverified** — reprojection threshold, board-to-volume ratio, Japanese retention period, published millisecond sync figures. They fail conservatively: each is already labelled a local decision, so a standard that does exist means the document understates its authority. Verify before strengthening any claim that rests on one.
- **Set predicates grade the governed units, not raw occurrence counts.** P03 requires `MUST` in each bound section: S14 has three, so lowercasing one leaves the obligation; S20's single `MUST` supplies the negative control. P05 binds each absence to `ABSENCE_SECTIONS`, checks preamble + row + governed span separately, and derives the label total as their sum. Each of the 13 labels is load-bearing; a stray label fails too. Firing: 13/13 single-label deletions fail, each with its own message.
