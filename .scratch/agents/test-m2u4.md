## Phase 1 — contract ambiguities found

| # | predicate | what is underspecified | readings | why it matters |
| - | --------- | ---------------------- | -------- | -------------- |
| A01 | P01 | Public API for magnitude mode is unnamed. | Logical `magnitude=TRUE`; enum/string mode; separate helper. | Phase-2 tests must call a stable interface rather than pin an accidental spelling. |
| A02 | P02 | “No `median(diff(...))` cadence inference remains” can be lexical or semantic. | Ban the source form; ban the algorithm through helpers/aliases; behavior-only check. | A lexical test can reject equivalent refactoring, while behavior alone can miss a hidden legacy call site. |
| A03 | P03 | “Uses the default mode” does not say whether the call must omit or explicitly select it. | `nominal_fs(t)`; `nominal_fs(t, magnitude=FALSE)`. | Source checks and future-default safety produce opposite preferred forms. |
| A04 | P04 + invariant 1 | P04 names strictly descending input, while seed class 4 and the invariant describe malformed timebases broadly. | Only descending must publish; duplicates, reversals, and nonfinite timestamps must also publish. | It decides whether malformed variants become rows or disappear under P05. |
| A05 | P05 | “Usable positive intervals” has no evaluation stage. | Count finite positive deltas before gap filtering; count final inliers after filtering; count magnitudes in magnitude mode. | Exactly-one/two interval boundaries and malformed-group publication change. |
| A06 | P06 vs P07/P08 | P06 has no minimum span, but four-decimal quantisation cannot guarantee 1e-4 relative error on arbitrarily short clips. | P06 implicitly uses span ≥1 s; P06 uses a named fixture length; literal all-span guarantee. | C7.02/C7.03 make the literal reading mathematically impossible. |
| A07 | P06 | “No worse than” lacks comparison slack. | Exact floating inequality; compare analytic errors; allow IEEE tolerance. | Near-equal 100 Hz and long-span cases can fail from representation noise. |
| A08 | P07 | `span` is not defined for gaps or malformed order. | Last-minus-first observed span; max-minus-min; sum of retained inlier intervals; magnitude path length. | The stated bound changes, especially under descending and filtered gaps. |
| A09 | P07 | The bound is mathematical, but the predicate asks a test to pin `≤` without representation slack. | Strict float inequality; analytic/rational bound; small IEEE allowance. | A sound estimator can miss a strict binary comparison by one ULP. |
| A10 | P08 | “Sized to” does not fix the tolerance value or composition. | Exactly `1e-4`; `1e-4 + 1e-9`; derive from `TIMESTAMP_QUANTUM/1s`; larger conservative constant. | Every near-boundary verdict and the published literal depends on this ruling. |
| A11 | P08 + P12 | Existing `QC_POLICY_TOLERANCE` applies to both gap and coverage, but only gap duration contains estimator error. | Raise the shared tolerance for both; split estimator and representation tolerances; apply the new value only to gap. | A 1e-4 shared band admits coverage below 0.80 without estimator justification. |
